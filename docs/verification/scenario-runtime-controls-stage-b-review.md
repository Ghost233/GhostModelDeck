## Standards

管理页复用原模型库、引擎目录、保存实例和启动集合业务入口，表格只负责查询结果、排序和最多二十行的展示。共同形状集中在 ManagementTable，没有为三个页面复制数据源或持久化状态。

行为保护仍由业务入口执行：删除计划保留所有权和运行保护；共享 projector 在其他变体仍引用时不删除；菜单按稳定身份选择对象，排序不影响操作对象。Finder 走既有原生通道，详情只显示有限摘要与路径。

监控不发推理请求、不启动模型，不将 HTTP 接收容量当执行槽位；字段缺失与零值区分。已有运行身份、取消、隐藏页面及旧代次保护在写入窗口前复核。原生计数窗口按实例和运行身份保存，秒级合并且每阶段最多 64 点，没有绘图历史。未知阶段保持运行中，终态请求不再占执行格子。

原有工程标准和坏味道基线逐项核对后，未发现需进一步抽象或相邻重构的硬性缺口。格式与静态问题均已关闭；查询、预览、实际请求和原生资源操作仍处在各自边界。

结果：Standards 轴未关闭 P0／P1／P2 为 0。
