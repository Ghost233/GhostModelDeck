## Spec

依据 `docs/requirements/product-scope-and-launch-instances-spec.md`、ADR 0007 与继承的 ADR 0003，以及 #87–#89 的验收项。

- 独立实例入口已接入引擎区。模型库生产入口只创建实例；保存、复制和编辑使用完整快照，公开名独立于显示名。引擎切换草稿、override 与固定命令区沿用原编辑器。
- 实例与委员会共享名称池；显式重名先失败并建议数字后缀。HTTP、MCP 与 SDK 选择保存实例，不借用同文件的另一进程。未运行请求 503，旧名 404，不隐式加载。
- 普通 llama.cpp 启动仅健康、加载与身份核对。接口来源明确为所选引擎声明，真实不支持由显式请求失败；不将声明、健康或短文本结果当作概率成绩。
- 保存入口拒绝不完整参数文本违反 ADR 0003。原失败 `run-Syy3L6` 保留；现在保存原文，执行前校验，`run-Qebh6Q` 覆盖重新读取与零进程。
