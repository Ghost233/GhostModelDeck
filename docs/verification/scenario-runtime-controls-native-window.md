## 原始失败与验收边界

首次开启自动加载后重开，原生实例曾显示启动失败。相同配置手动重试成功，下一次相同配置自动重开也成功。原因未确定；保留首轮失败，不宣称根因已修复。GMD 显示真实失败，没有换模型或自动循环重试；当前没有证据将该次引擎失败归为 GMD 控制缺陷。

原生输入工具的 setValue、粘贴和焦点曾未可靠提交文本，取消后改用正常键盘输入，核对实际保存文件及重开结果。本轮成功编辑使用 ASCII 场景名，中文输入没有记为原生通过；中文显示与字体布局仍由真实字体测试覆盖。

隔离壳曾因 final 修饰、包导入或文件名产生构建／分析失败，已在同一壳内定点修正。监听日志文件存在并发写入截断，最终端口按可见 MCP 地址和实际协议握手核对；没有因此修改产品或重建应用。最终发现脚本最初错误读取 `models` 字段，退出 1，原响应实际为 `data: []`；修正脚本字段后同一只读检查退出 0。以上均保留为执行器失败，不记作产品红灯或成功。

本轮不重新测试每个模型，不恢复质量题集，不替代既有 Finder、历史和回放验收，也不切换正式 GMD。
