# 菜单栏与图标调整

2026-10-08，按用户最终选择：主窗口打开时显示 Dock，关闭后隐藏 Dock、保留菜单栏和后台服务；菜单栏提供打开主窗口与明确退出。菜单栏与启动器使用同一个窗口激活方法。

新图标使用内置 image_gen，参考 Ghost Nexus 的配色与幽灵风格，改为模型卡片主题。母版和最终提示词见 [图标来源](../../assets/branding/README.md)，macOS 的七档 AppIcon 资源已更新。

最终 Mac Release 构建真实退出 0。只读检查实际应用的激活策略，开窗、关窗、重开分别为 regular(0)、accessory(1)、regular(0)，三次均使用 PID 27196。关窗后 HTTP 服务仍返回 200；明确退出后原进程的监听全部释放。原应用配置和既有 `.gitignore` 修改保留。

Dart 的 98 个门禁输入未变化，复用此前 format 零改动、analyze 零诊断、540 项测试证据；原生部分使用本次构建和上述实机检查。原始材料保存在 `.scratch/dock-menu-icon/`。

系统菜单栏的自动化查询超时，菜单项未被自动化直接点击。窗口重开与退出分别验证了它们共享的激活和退出路径。界面查询会重开刚关闭的窗口，因此关窗策略检查直接读取进程，不在两者之间查询界面。临时诊断代码已删除。
