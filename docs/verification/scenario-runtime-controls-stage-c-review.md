## Standards

自启动保存沿用 StartupModelSet，在同一原子文件中增加可选布尔字段，不建立第二份实例列表。设置页和实例表观察同一变化源，保存失败不提前发布。资源准备集中于已有 LaunchInstances 业务所有者，页面与自动启动复用它，未引入额外状态框架。

新增两个 catalog 回调分别用于应用组装中的所选实例自动加载和批次取消；它们有实际调用方，未增加推测性平台或引擎支持。类型判断只用于选择现有运行资源是否需要停止，不复制各引擎停止算法。已按坏味道基线核对命名、重复、职责、消息链和不必要抽象，没有需扩大重构的发现。
