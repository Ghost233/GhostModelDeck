# llama.cpp 草稿配置范围调整

2026-10-20。来源为用户在实施期间的明确回复。本文件补充 [A 方案：实例参数控件、生成默认值与显式草稿模型](https://github.com/Ghost233/GhostModelDeck/issues/118)，保留原规格正文。

## 用户确认

用户取消 llama.cpp 每种草稿模式的真实兼容配对验收，要求提供模式、路径和参数控件，按官方方式构造启动参数。

用户随后澄清：“按照 llama.cpp 的方式来，能运行就运行，不能运行就不能运行。”这表示原生程序决定运行结果，GMD 不增加草稿兼容性或活跃状态的致命判断。

## 替代的要求

- 提供普通 draft、EAGLE3、MTP、DFlash 和 DSpark 单选，以及各模式按当前官方版本需要的资源路径和调优控件。
- 按所选安装的官方 CLI 规则构造参数。模式可能具有不同的资源要求，不强制套用同一种独立草稿文件规则。
- 原生程序就绪后允许使用；GMD 不因 slots 缺失、未暴露草稿活动或原生自行回退而额外拒绝就绪、关闭进程。
- 原生启动失败继续显示实际错误并按现有生命周期收尾。该调整不要求保留已经死亡、失去运行身份或无法服务的进程。
- 草稿观测须如实展示。原生就绪不等于草稿已启用，未知状态不能冒充启用。
- 本次不以每种模式的真实模型配对、实际草稿活动或短生成作为结项门槛，使用公开配置、命令和进程 I/O 行为验证适配。

## 继续适用的要求

显式来源、单一草稿模式、文本调优优先、关闭后忽略旧来源、ngram 策略、实例隔离及在用保护保持有效。保存和预览不准备或启动模型，选择取消不覆盖已有值。

Splash 的显式草稿、真实加载、compact 验证和失败语义不受本调整影响。认证、生成默认值及其余公开请求契约也继续按原规格交付。

当前 b11457 的官方参数来源为 [固定提交的参数声明](https://github.com/ggml-org/llama.cpp/blob/5ad1c5da0ad7f6176256b823925aad19134f0263/common/arg.cpp)。其他安装仍以各自版本为准。

## 工单归属

本调整主要由 llama.cpp 草稿配置子项承接。运行实例整合与最终交付工单须采用相同边界，不再把上述真实资源配对作为阻塞。父规格标题、正文和开放状态保持原样，当前实施索引记录调整后的验收范围。
