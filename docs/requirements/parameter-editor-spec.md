# 参数编辑与显式草稿模型配置

## 来源与范围

2026-10-20，用户完成 Q1～Q9 讨论，并选择 A 方案。界面参考 LM Studio 的类型化控件，在现有实例编辑入口采用分组侧栏。llama.cpp 与本机自定义 Splash 均支持可视化配置。已有用户文件、权重、引擎和服务保持原归属。

设计依据见 [ADR 0009](../adr/0009-explicit-drafter-configuration.md) 和 [ADR 0010](../adr/0010-instance-generation-defaults.md)。自定义 Splash 的 40 项共享 CLI 选项及生成字段清单见 [参数分析](parameter-editor-analysis.md)。本次不改写原始模型 config，不隐式下载或转换权重，不开展性能测试。

## 配置与生效

- 每份实例保存独立参数，不将一份草稿模型全局套用到多个模型。
- 加载、内存、上下文、缓存和草稿资源配置在下一次启动生效，保存不自动重启。
- 生成默认值按实例保存，从下一次请求生效。已提交请求使用其准入时确定的参数。
- 单次请求显式值优先于实例生成默认值，实例生成默认值优先于引擎默认值。测试场通过同一个公开业务入口调用。
- 启动文本中的同名调优参数继续优先于对应启动表单值。软件管理的模型来源和草稿开关保持独立规则，并提示冲突字段。
- 关闭输出长度限制时不人为补入 32 或 4096。具体预算由引擎与上下文决定。

## A 方案控件

侧栏按生成和加载职责分组，支持查找参数。布尔值使用开关或三态选择，枚举使用下拉框，数值提供精确输入，适用时配合滑块或步进。目录与文件提供选择器，字符串列表提供增删控件，结构化输出提供格式选择和 Schema 编辑器。

折叠高级区同样提供控件。用户可以在正常配置流程中完成所有已知可调参数的设置，不要求手写 CLI。引擎帮助中额外识别的参数也可通过参数项编辑；不把软件管理字段作为普通输入项。命令文本保留为可选入口。

界面明确显示继承或覆盖状态、生效阶段、版本适用性和失败原因。保存和预览不准备模型或启动服务。参数的实际支持与限制来自当前引擎，不能把截图示例值或源码编译默认值冒充实际运行值。

## 草稿模型

Splash 选择原始 safetensors 目录。GMD 在自己管理的 assembly 中创建引用，保留目标模型路径和原始权重。检查 config、权重或索引及全部分片，调用所选 Splash 的原生 model-check 验证配置兼容性，启动时由原生检查实际张量结构。

llama.cpp 选择 GGUF 草稿模型，分片模型使用首片。提供普通 draft、EAGLE3、MTP、DFlash 和 DSpark 模式单选。启动检查全部分片，通过受控最终模式、原生加载和实际 slots 状态核实启用结果。

开启时只使用明确选择的来源。文件缺失、结构错误或不兼容时明确失败，不自动改选其他目录。关闭“使用草稿模型”后不加载草稿资源，历史路径和值可保留以便编辑；不加载草稿模型的 ngram 配置仍可生效。开启草稿时暂不同时激活 ngram，并提示保存值与实际值的区别。

不支持草稿的决策路径不得因尺寸相同而附加 Qwen 草稿。后端必须有草稿时，界面和启动错误说明原因。旧 assembly 的路径只作修复线索，不能代替显式选择。

配置变化后重新准备对应绑定。原运行实例继续持有原资源，新的生成默认值不改变其加载配置。草稿权重与目标权重共用现有在用保护和退出收尾。

启动检查展示请求开关、实际阶段、实际来源、类型和失败原因。文件检查或配置检查通过不等于模型已加载。compact 的正常完整 head 回退与草稿加载失败分别表达。

## 引擎参数

llama.cpp 的草稿常用项包括最大和最小 token 数、概率阈值和 GPU 层数。设备、线程、KV 格式和当前版本支持的采样选项放入高级组。参数空值继承引擎默认。

Splash 的运行配置按当前自定义版本已有 CLI 选项提供，覆盖内存、状态格式、SSD 缓存、服务预算、ANE、功耗恢复、编码器、提示查找、compact 和通用采样优化。compact 默认关闭，开启时需要 ranking 文件，按原生格式和词表规则检查。

Splash 的采样、惩罚、停止字符串、结构化输出、思考和请求调度等生成设置，通过现有原生请求接口应用。GMD 适配字段名差异。CLI 未提供的中间截断或统一消息裁剪行为不在本次追加。
