# 基准批次独立于测试场页面生命周期

2026-10-09，用户确认基准评测切换 Tab、离开页面或关闭窗口后继续运行，页面可以重新查看进度并主动取消；明确退出应用时停止评测，保存已完成结果并标记中断，重启只查看历史而不自动续跑。相比让页面销毁直接取消整个基准，这使长任务不依赖用户停留在某个界面；应用退出又保留明确的资源收尾边界。

基准任务的归属与持久记录由应用管理，页面只观察与操作当前任务。基础推理测试仍在离页时取消并保留输入和已有输出，不能将这两种生命周期混用。取消、中断、失败与完成分别记录，不能把部分结果宣称为完整通过。完整讨论见 [测试场与基准需求](../requirements/playground-and-benchmarks.md)；本记录为已确认的设计，不表示后台批次或历史功能已实现。
