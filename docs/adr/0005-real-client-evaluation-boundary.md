# 测试场通过真实公开入口评测

2026-10-09，用户确认测试场仅使用已 Ready 的模型与委员会，并强调基础推理测试及基准都要模拟正常客户端，通过实际 HTTP 或 MCP 请求执行，不能直接调用内部推理接口。相比内部函数调用，这同时验证公开发现、模型路由、请求校验、推理、协议返回及客户端可用的取消行为，使测得的结果和延迟代表实际使用链路。

测试客户端不保留绕过公开入口的原生内部通道，也不使用仅进程内可取得的请求 lease 或特殊登记 header 获得取消特权；服务端仍沿用既有生产控制器和运行实例。HTTP/MCP 的选择及指标分开记录，不能把内部耗时冒充客户端端到端耗时。此决定替换 ADR 0001 及原测试场规格中的原生模式边界，保留标准 JEV 输出、委员会聚合与服务器资源管理契约；通用 LLM 当前公开 HTTP JSON/SSE 与 JEV HTTP/MCP 分别按能力支持。本记录是已确认边界，尚未实施，完整讨论见 [测试场与基准需求](../requirements/playground-and-benchmarks.md)。
