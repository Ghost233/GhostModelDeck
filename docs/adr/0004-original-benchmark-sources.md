# 使用锁定版本的上游原题作为基准来源

2026-10-09，用户明确选择通过 Git submodule 引入上游基准题源，并要求只采用来源发布的原始题目，不由代理翻译或改写，取消题目语言限制。相比维护翻译副本或直接复制题目，这保留原题、标签与评分规则的来源，方便跟踪上游更新；固定子模块提交则使既有评测仍能引用同一版本。

主仓库保存原题引用、套件清单、运行适配与评测记录，上游题目保持原样。首批五项为 DecideBench、JEVal、一致性 JevBench、JevAdvBench、Jevman；只提供完整评测，Jevman 默认 100 局。更新题源须记录新版本并验证题目、格式和评分适配，通过后随应用发布受支持的固定版本；安装版首次下载并缓存该版本，不要求用户安装 Git，不追踪上游最新提交或隐式改变在途批次。旧版本保留历史引用。本 ADR 不表示子模块或评测功能已实施。讨论见 [测试场与基准需求](../requirements/playground-and-benchmarks.md)。
