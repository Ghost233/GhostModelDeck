# 实例显式选择草稿模型

2026-10-20，用户确认 Splash 和 llama.cpp 都提供 drafter 开关、本地草稿模型选择及常用参数表单。配置沿用 ADR 0007 的实例参数快照，各实例分别保存。具体字段和控件按当前引擎能力确定，已知可调参数均可在界面配置。

草稿模型来源由用户明确选择。安装目录中的固定路径和尺寸相同的候选模型不能代替选择。旧路径只作为修复线索，避免实例加载未经选择的模型。

用户确认开关和草稿模型选择属于软件管理字段。高级文本与这两项冲突时，软件剔除冲突参数并提示实际采用值。调优数值继续遵循 ADR 0003 的文本优先规则。该取舍保证关闭 drafter 后不加载草稿模型资源。

用户进一步确认开关命名为“使用草稿模型”。关闭时只禁用草稿模型，高级文本中的 ngram 等无草稿模型推测解码模式仍可生效。

llama.cpp 提供普通 draft、EAGLE3、MTP、DFlash 和 DSpark 模式单选，由用户明确选择。模型元数据用于提示，原生加载用于兼容性验证。启用草稿模型时只执行所选草稿模式，暂不应用文本中的 ngram 激活配置，并显示提示。现有原生状态无法独立报告混合模式中各推测实现的活动状态，因此首版采用可核实的单草稿模式。

llama.cpp 常用表单包含最大和最小草稿 token 数、概率阈值和 GPU 层数。设备、线程、K/V 缓存类型及当前版本支持的草稿采样选项放入折叠高级区。空值使用引擎默认值，调优数值继续文本优先。

Splash 在折叠高级区提供 compact draft head 开关、ranking 本地文件选择和 compact 词表容量。compact 默认关闭，启用时检查 ranking 的原生格式和完整性。界面分别显示请求设置与实际状态，原生正常回退完整 head 时如实提示。fast-topk 属于通用目标采样优化。草稿长度遵循引擎的编译执行约定。

Q1～Q7 已逐项确认。用户随后追加本版本的参数编辑改进，要求先分析 LM Studio 截图。llama.cpp 和当前自定义 Splash 版本中面向用户的可调参数均应提供符合参数类型的可视化控件，使用配置界面即可完成设置。该补充取代此前将已知参数仅留在高级文本中的安排，fast-topk 也应在通用采样参数区提供开关。高级分组仍使用控件，用户无需手填已知 CLI 参数。

2026-10-20，用户选择 A 方案，正式界面采用分组侧栏。配置与生成设置按已确认范围继续实施。本记录不表示功能已经完成实施或验收。

生成默认值的归属和生效方式见 [ADR 0010](0010-instance-generation-defaults.md)。
