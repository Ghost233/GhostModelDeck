# 模型路由由用户指定当前实例

客户端使用固定调用名访问模型路由。用户在 GMD 保存一组候选实例，从中指定一个处理请求。这让用户可以在内存只够运行一个实例时手动安排启停，也能确定每次调用使用哪个模型。路由调用名与实例、委员会和场景共用同一名称空间。

公开 API 在接收请求时确定实际实例。协议、模型能力、生成默认值和容量取自当前实例。普通响应与流式响应都使用路由调用名。当前实例没有请求所需的能力或尚未就绪时，对应的发现列表隐藏路由，直接请求返回 `503 model_not_ready`。实例启停由用户在实例页控制。

切换后，新请求采用当前实例，已接收的请求继续使用原实例。可追踪预填充按操作登记时的实例和运行代次查询或重试。客户端启动新操作前需要获取当前路由的运行代次。

Responses 请求可以用 `previous_response_id` 跨实例续接。GMD 按路由名在内存中保留输入和输出，最多保留 256 条、共 16 MiB，单条上限为 1 MiB。设置 `store: false` 时不保留该响应。历史被清除或淘汰后，客户端需要重发对话历史。
